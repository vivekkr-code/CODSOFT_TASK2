# CODSOFT Task 4 - Sales Prediction Using Python

## Overview
This project is part of the CODSOFT Data Science Internship. The objective is to predict product sales based on advertising expenditure using Python and Machine Learning.

## Objective
To build a Linear Regression model that predicts Sales using advertising spending on TV, Radio, and Newspaper.

## Dataset
The dataset contains the following columns:

- TV
- Radio
- Newspaper
- Sales

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow

1. Import required libraries
2. Load the advertising dataset
3. Explore the dataset
4. Check missing values
5. Perform statistical analysis
6. Analyze correlations
7. Create data visualizations
8. Split the data into training and testing sets
9. Train a Linear Regression model
10. Make Sales predictions
11. Evaluate the model using MAE, MSE, RMSE, and R² Score
12. Visualize Actual vs Predicted Sales

## Machine Learning Model

Linear Regression was used to predict Sales from:

- TV advertising expenditure
- Radio advertising expenditure
- Newspaper advertising expenditure

## Model Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Conclusion

This project demonstrates how machine learning can be used to analyze the relationship between advertising expenditure and sales and predict sales using Linear Regression.
